# RESTAPI - SPRING BOOT

Olá! Essa é uma REST API feita por mim do zero utilizando Spring Boot.

## TECNOLOGIAS UTILIZADAS

| TECNOLOGIA | FUNÇÃO |
|---|---|
| JAVA | Linguagem utilizada |
| SPRING BOOT | Framework utilizado para desenvolver a API |
| H2 | Banco de dados |
| MAVEN | Gerenciador de dependências |

## COMO RODAR (TERMUX)

### 1. Instale o Git

pkg update && pkg install git

### 2. Clone o repositório

git clone https://github.com/bnzinn1/SpringBoot

### 3. Acesse a pasta

cd SpringBoot

### 4. Instale o Maven

pkg update && pkg install maven

### 5. Execute o projeto

mvn spring-boot:run

### PRONTO!

Depois disso, sua API estará rodando!
